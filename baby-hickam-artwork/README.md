# Baby Hickam artwork

Transparent PNG and SVG artwork prepared for the Baby Hickam React site.

The production hero is composed from these standalone sources with CSS. Keep Baby Hickam, Tyler & Austin, dates, buttons, and event information as semantic HTML.

`shoreline-repeatable.png` is converted to an optimized WebP for production. `seashell.png` and `palm-tree.png` are cropped to their painted bounds before being copied to `public/assets`.

See `ASSET-MANIFEST.json` for the current asset inventory and crop guidance.
